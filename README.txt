# eli.print DIY Photobooth

## Upload to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Optionally keep the `images/` folder for future assets.
4. Open Settings → Pages → Deploy from branch → main → /root.
5. Open the generated Pages URL using HTTPS so camera permissions work.

## Client features
- 2–6 camera takes
- Front/back camera
- 3/5/10 second countdown
- Custom business logo upload, saved in the browser
- 8 frame templates
- Text templates requested by Eli PrintHub
- Custom text, font, size, color and position
- Hearts/stickers
- 2×6 strip, 4×6 and A4 layouts
- Download PNG soft copy
- Browser print dialog
- Photos are processed locally in the browser

## Important printing note
The 2×6 output is rendered at 600px wide in the browser preview. For professional lab printing, use the 4×6/A4 output or adapt the canvas dimensions to your printer's exact DPI workflow.
